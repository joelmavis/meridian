# Meridian

Meridian 是全球 AI 治理、AI 安全与 AI 监管情报雷达。它不是泛 AI 新闻聚合器：它每天从可追溯来源中筛选 10 条真正值得研究、讨论或转化为内容的变化，并以可直接打开的 HTML 晨报交付。

## 它解决什么问题

每天都有政策、企业公告、研究论文、社交媒体讨论和媒体报道出现。难点不在于“找到更多”，而在于辨别哪些变化值得占用研究时间，以及它们是否有可靠来源。

Meridian 把这个过程固定为一条轻量工作流：按事件去重、优先回到原始资料、保留反向信号，并将每条消息连接到一个合适的后续用途。

## 安装

Meridian 遵循通用 Agent Skill 目录结构，仓库根目录的 `SKILL.md` 是调用入口。

### Codex

```bash
git clone https://github.com/joelmavis/meridian.git ~/.codex/skills/meridian
```

重新打开 Codex 会话后：

```text
使用 $meridian 生成截至北京时间今天 07:00 的全球 AI 治理晨报。
```

### Claude Code

```bash
git clone https://github.com/joelmavis/meridian.git ~/.claude/skills/meridian
```

重新启动 Claude Code 或开启新会话后，使用 `/meridian`，也可以在任务中明确要求调用 Meridian。

### 其他 AI Agent

如果 Agent 支持包含 YAML frontmatter 的 `SKILL.md`，将本仓库复制到其 Skills 目录即可。执行实时雷达还需要联网检索与网页读取能力；Meridian 本身不提供搜索 API、付费媒体权限或定时器。

## 监控范围

Meridian 关注全球范围内会改变下列问题的动态：

- 政府、监管机构、联合国、欧盟、东盟、非盟、APEC、OECD 等国际组织的政策、标准、法律、实施与执法；
- 高校与研究机构的 AI 治理、安全与监管研究；
- AI 企业的官方政策、部署承诺、安全研究、治理机制与重大披露；
- 企业领导者、产品与技术负责人的公开 X 动态；
- 研究员、政策研究者和行业从业者的公开讨论；
- 权威媒体、LinkedIn、Medium、Reddit、Substack、播客和专业博客中的高价值线索与分析。

普通产品发布、融资、跑分或无实质变化的表态默认不进入晨报，除非它们直接改变 AI 治理、AI 安全或监管问题。

## 每日报告如何工作

1. 扫描过去 24 小时的分层来源；周一回看周末至报告基准时间。
2. 以事件而非报道篇数去重。
3. 对政策、数据、法规和关键事实尽量回到一手来源。
4. 固定筛选并排序 10 条消息：其中 3 至 5 条为已核验的 X 原帖，默认 3 条；优先 P1/P2，必要时以可靠、直接相关的 P3 补足。
5. 每条标明重要性、优先级、事实状态、为何值得关注、适合转化的内容类型和来源链接；X 条目另标明作者／机构、语言与来源类型。
6. 在结尾分开呈现可确认事实与基于事实的推论，并只给出一项当日行动建议。

报告采用完整 HTML 与内联样式，可直接保存为 `.html` 后在浏览器打开。它不会自动发帖、自动回复或替使用者做最终判断。

## 输出字段

| 字段 | 含义 |
| --- | --- |
| 重要性 | 高／中／低，表示议题本身的研究与公共影响 |
| 优先级 | P1／P2／P3，表示应否立即跟进 |
| 发生了什么 | 已确认事实与尚待核实主张分开写 |
| 适合做什么类型内容 | 深度研究、快评文章、短视频、X 讨论帖、播客选题或观察清单 |
| 来源 | 至少一个可访问链接；社交或媒体线索尽量补回一手资料 |
| X 原帖 | 每日 3 至 5 条，标明作者／机构、原帖语言和可访问链接；涉及事实时补一手来源 |

每天必须有 10 条真实且可追溯的消息，其中 3 至 5 条来自公开、可访问、身份可核验的 X 原帖。若高优先级变化较少，Meridian 会补入可靠的 P3 研究、背景或讨论信号，并清楚说明为何它尚未构成重大变化；不会用无关信息或虚构来源凑数。若检索条件下无法可靠核验至少 3 条 X 原帖，会明确报告 X 覆盖不足与原因，而不是伪造内容。

## 判断边界

正式取证顺序为：官方原始资料、原始论文／数据与研究机构报告、企业官方披露、权威媒体、社交媒体／播客／博客／论坛。企业公告只能证明其自身的声明或承诺；社交媒体适合发现线索与呈现讨论，不应单独证明政策、数据或因果关系。

Meridian 会主动保留安全争议、监管受阻、企业抵制、执行落差和政策退坡等反向信号。它可以提出“这可能意味着”，但不会替使用者宣布长期趋势成立或形成最终立场。
